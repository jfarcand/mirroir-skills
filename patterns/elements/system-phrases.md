# System Phrases

Words iOS itself draws on its system screens, which mirroir reads to tell that
the phone left the app it was driving. The iPhone's language is not known to
the Mac, so each section is a union across languages: add a phrase the way it
reads on a phone in that language, lower-cased, one per bullet. A fragment is
enough, as long as no ordinary app screen would contain it.

This file is data, not a component: it has no match rules.

## Lock Screen

Text of the lock screen and the passcode prompt.

- slide to unlock
- enter passcode
- face id
- swipe up to open
- press home to open
- emergency
